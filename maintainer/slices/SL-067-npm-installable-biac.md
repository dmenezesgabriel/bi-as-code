# SL-067 — `npm i biac` gives a working `biac build` and `biac dev`

Milestone: Phase 9 — Open-source release · State: open · Depends on: SL-063 · Closes: GAP-092, GAP-093, GAP-094, GAP-095, GAP-098

> Delete this file when the slice ships. Every number below carries the command that printed it, run 2026-11-09 on this host; scratch installs lived under `~/.cache/biac-sl067` (ext4) and are deleted.

## Outcome

A user runs `npm i -D biac` (or `pnpm add -D biac`) in an empty directory, writes `pages/index.md`, and `npx biac build` and `npx biac dev` work, with the echarts and zrender fixes intact and the tarball under a measured size budget.

## Demo

1. Cold start in the repo: `pnpm build:cli && cd $(mktemp -d --tmpdir=$HOME/.cache) && npm pack /path/to/repo` (the `prepack` script builds the CLI).
2. In a second empty directory: `npm init -y`, `npm i ../biac-0.1.0.tgz`, then `mkdir -p site/pages && printf '# Hello\n' > site/pages/index.md`.
3. `npx biac build site` exits 0 and `site/build/index.html` exists; `grep -l '_redrawId=null' site/build/assets/*.js` lists one file (the zrender fix is in the bundle).
4. `npx biac dev site --port 5199`, open `http://localhost:5199/`, the page renders with the app's styling (sidebar, theme toggle); no console error beyond the tracked Known-debt entries.
5. Repeat 2–4 with `pnpm add ../biac-0.1.0.tgz` and `pnpm exec biac …` (pnpm blocks install scripts by default, so this proves no install script is needed).
6. Build `docs/` from the install (`npx biac build <copy-of-docs>`): 48 `index.html` files, the same count as `find docs/build -name index.html | wc -l` in the repo.

### Patch delivery, three options measured (GAP-094)

| Option                                                         | Tarball cost                                                                                                                          | Dev (`biac dev`)                                 | Build (`biac build`) | Survives pnpm                                                           | Notes                                                                                                                                                                                                          |
| -------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------ | -------------------- | ----------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Vite plugin: `transform` plus `optimizeDeps.rolldownOptions`   | +675 B (330,381 B packed, 363 files)                                                                                                  | patched                                          | patched              | not applicable (no install step)                                        | Anchor text is checked and the build throws when an echarts upgrade moves it; output equals the pnpm-patched source except the 3 comment lines per file (checked by applying the plugin to the pristine files) |
| `bundledDependencies` of patched `echarts` and `zrender`       | 13,473,617 B packed, 65,698,047 B unpacked, 2,085 files                                                                               | patched                                          | patched              | yes (patched copy found under `node_modules/biac/node_modules/echarts`) | 41× the tarball; ships a modified echarts that `npm ls` reports as an unmodified `echarts@6.1.0`                                                                                                               |
| In-tree copy of the patched `lib/` directories under `vendor/` | about 997,485 B gzipped, 5,621,760 B raw (tar of `echarts/lib`, `echarts/*.js`, `zrender/lib`, `zrender/index.js`; not an `npm pack`) | needs aliases for 5 echarts subpaths and zrender | same                 | n/a                                                                     | Frozen at 6.1.0, needs aliases for `echarts/core`, `/charts`, `/components`, `/features`, `/renderers`, and carries the libraries' licence files                                                               |
| Install script (postinstall patching)                          | excluded by the ledger decision                                                                                                       | —                                                | —                    | no (pnpm ignores it, `allowBuilds`)                                     | measured side effect: pnpm printed `Ignored build scripts`                                                                                                                                                     |

**Decision:** the Vite plugin. It costs 675 B against 13.1 MB or about 1.0 MB, patches dev and build, and fails loudly on drift. The plugin must replace the pnpm `patchedDependencies` in the same task: the anchor line survives in an already-patched file, so applying both would insert each fix twice.

## Trade-offs and what we adopt

| Axis                      | Options seen (repo → approach)                                                          | Trade-off                                                                  | Our choice, and why                                                                                                                                                                                    |
| ------------------------- | --------------------------------------------------------------------------------------- | -------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| What the tarball contains | framework → `files` allowlist; streamlit → prebuilt static dir; ours today → no `files` | A prebuilt shell cannot hold the user's pages                              | `files` allowlist with source `src/web`, compiled `dist/cli` and `dist/engine`                                                                                                                         |
| Where runtime deps live   | ours today → 20 SPA deps in the private workspace `src/web/package.json`, 3 in the root | A published manifest needs every runtime dep in the root; two copies drift | Move the SPA runtime and the build-time libraries (`@mdx-js/mdx`, the vite plugins, `tailwindcss`, remark and unist libs) to the root `dependencies`; `src/web/package.json` keeps its devDependencies |
| Patch delivery            | evidence → pnpm patch (monorepo only); measured three options above                     | Size, drift, licence                                                       | Vite plugin (table above)                                                                                                                                                                              |
| Size budget               | measured 330,381 B packed                                                               | Too loose hides a re-added `dist/web`; too tight fails on a new widget     | 500,000 B packed and 1,650,000 B unpacked in a test over `npm pack --dry-run --json`; revisit when a real feature pushes past it                                                                       |
| `@tailwindcss/vite` peer  | measured duplicate `vite@6.4.5`                                                         | Bump touches every style                                                   | Bump `tailwindcss` and `@tailwindcss/vite` to the first release allowing vite 8 (≥ 4.2.2, exact pin, subject to `minimumReleaseAge`), prove with a before/after class-selector diff (T2)               |

## Deviations

- The tarball ships the SPA as source, unlike framework and streamlit, which ship a built client: biac bundles `pages/` into the SPA, so the shell is built per project.
- The patch plugin replaces `patchedDependencies` instead of sitting beside it (double insertion), which also removes `patches/`.
