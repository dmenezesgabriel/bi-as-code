# SL-063 — The repository is safe to open

Milestone: Phase 9 — Open-source release · State: open · Depends on: R12 (shipped) · Closes: GAP-084, GAP-085, GAP-086

> Delete this file when the slice ships.
>
> Every path below was checked with `test -e` (or `gh api` for the owner's repositories) on 2026-11-06. Line ranges are omitted on purpose.

## Outcome

Everything a stranger needs to trust and use the repository is in it — a license, a security policy, contribution rules, code owners, issue and PR templates — nothing in the tree or its history is a secret, and no source file points at planning documents or at a reference repository's file paths. The repository stays private until SL-068 ships (owner, 2026-11-06); this slice makes it safe to open, and the owner opens it last.

## Demo

1. From a clean clone: `ls LICENSE NOTICE SECURITY.md CONTRIBUTING.md .gitleaks.toml .github/CODEOWNERS .github/PULL_REQUEST_TEMPLATE.md .github/ISSUE_TEMPLATE` lists every file.
2. `head -3 LICENSE` shows the Apache License 2.0 header and `grep -n '"license"' package.json` shows `Apache-2.0`.
3. `git grep -nIE "\b(SL|GAP)-[0-9]{3}\b" -- . ':!maintainer' ':!AGENTS.md' ':!prompt-execution.md'` prints nothing.
4. `git grep -nIE "research_repos|\.svelte\b|core/src/user-components|lib/streamlit" -- src test scripts pages docs examples` prints nothing.
5. `gitleaks git --redact` over the whole history (638 commits at writing) exits 0 with the committed `.gitleaks.toml`.
6. `gh repo view dmenezesgabriel/bi-as-code --json licenseInfo` reports `Apache-2.0` once pushed (the repository may still be private).
