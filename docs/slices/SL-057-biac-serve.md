# SL-057 — `biac serve`: the hardened production server over `build/`

Milestone: Phase 7 — Self-hosting and authentication · State: open · Depends on: R10, SL-056 · Closes: GAP-057, GAP-058, GAP-059

## Outcome

`bin/biac serve` runs a hardened production server over a project's `build/`: HTTP basic auth from `BIAC_BASIC_USER`/`BIAC_BASIC_PASSWORD` (or the explicit `BIAC_AUTH_DISABLED=1|true` opt-out), a refusal to start beyond localhost with neither, `X-Content-Type-Options` and `Referrer-Policy` on every response beside the existing framing policy, and the static-host contract `biac preview` already keeps — byte ranges, data media types, per-route `index.html`, the `404.html` document, and the `embed` CORS grants.

## Demo

1. Cold start: `pnpm build:cli && bin/biac build` in the repo root — the project's own `build/`.
2. `BIAC_BASIC_USER=viewer BIAC_BASIC_PASSWORD=s3cret bin/biac serve --port 8933` — prints the bound URL and the auth mode. `curl -i http://localhost:8933/weekly-review` → `401` with `WWW-Authenticate: Basic realm="biac", charset="UTF-8"`; `curl -u viewer:s3cret -i …` → `200` with `X-Content-Type-Options: nosniff`, `Referrer-Policy: no-referrer`, `Content-Security-Policy: frame-ancestors 'none'`, `X-Frame-Options: DENY`.
3. Ranged read under auth: `curl -u viewer:s3cret -H 'Range: bytes=0-3' -i http://localhost:8933/data/flights.parquet` → `206`, `application/vnd.apache.parquet`, `Content-Range: bytes 0-3/<size>`.
4. Routes: `curl -u … -i http://localhost:8933/nested/allocation` → `301` to `/nested/allocation/` → `200`; `curl -u … -i http://localhost:8933/nope` → `404` whose body is `build/404.html` (the SPA's not-found page); `curl -u … -i http://localhost:8933/data/nope.parquet` → `404`, not the shell's `200`.
5. Boot guard: `bin/biac serve --host 0.0.0.0` with no env → exit `1` naming `BIAC_BASIC_USER`, `BIAC_BASIC_PASSWORD` and `BIAC_AUTH_DISABLED`; `BIAC_AUTH_DISABLED=yes` still refuses (only `1`/`true` disable); `BIAC_AUTH_DISABLED=true bin/biac serve --host 0.0.0.0` → starts with a loud warning; `BIAC_BASIC_USER=viewer` alone → a warning that the pair is half-set.
6. Browser: `playwright-cli` with `httpCredentials` `viewer`/`s3cret` (a `user:pass@` URL makes the browser refuse every `fetch()` — measured 2026-10-25: `Request cannot be constructed from a URL that includes credentials` on the duckdb wasm) on `http://localhost:8933/weekly-review/` — the page renders, picking a filter re-queries (data files answer under auth), console stays clean.

## Trade-offs and what we adopt

| Axis                | Options seen (repo → approach)                                                                                                    | Trade-off                                                                                                                                                              | Our choice, and why                                                                                                                                                                                                                  |
| ------------------- | --------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| Server substrate    | evidence → Bun server + SvelteKit hooks; ADR-0008 → vite `preview()` over the folder; an own Node `http` server                   | vite preview keeps sirv's ranges/etags/media types and the base handling; an own server re-implements them — the con ADR-0008 already weighed                          | vite `preview()` with `configurePreviewServer` middlewares — auth and headers mount ahead of sirv, so every response is covered (evidence's static-branch lesson); verified in `src/cli/commands/preview.ts` and vite 8.2.2's source |
| Unmatched routes    | vite `appType: "spa"` → `200` + shell (today's preview); `appType: "mpa"` + a post-hook → `301` to `path/`, `404.html` with `404` | spa parity keeps preview identical; mpa is what real hosts do and honors the build's own `404.html`                                                                    | O1 — recommend `mpa` + post-hook: truthful status codes, and `serve` becomes meaningfully different from `preview`                                                                                                                   |
| Credential compare  | evidence → length short-circuit + `timingSafeEqual`; hash-then-compare                                                            | the short-circuit leaks the credential's length by timing                                                                                                              | SHA-256 both sides, then `timingSafeEqual` — no length leak                                                                                                                                                                          |
| Header set          | evidence → `nosniff`, `no-referrer`, `XFO DENY`; OWASP → adds HSTS, COOP, CORP                                                    | `Cross-Origin-Resource-Policy: same-site` would block the shipped `/data/` + `/widgets/` cross-origin embeds; HSTS is inert over HTTP and the terminator's header (D3) | `nosniff` + `no-referrer` added; framing stays `frameAncestorsMiddleware` (XFO rides it); `Cache-Control: immutable` on hashed `<base>assets/`; no HSTS/COOP/CORP                                                                    |
| Referrer-Policy     | evidence → `no-referrer`; OWASP → `strict-origin-when-cross-origin`                                                               | our URLs carry filter state (`?region=West`); strict-origin still names the origin and path shape cross-origin                                                         | `no-referrer` — tightest, and the app reads no Referer                                                                                                                                                                               |
| Host header check   | vite's default `allowedHosts` → 403s any served domain; `allowedHosts: true`                                                      | the check protects dev against DNS rebinding; a production server behind a LB/proxy receives the public Host                                                           | `allowedHosts: true` — the deployer owns the perimeter                                                                                                                                                                               |
| Middleware location | duplicate the four preview plugins in `serve.ts`; extract a shared module                                                         | duplication drifts                                                                                                                                                     | extract the four static plugins into a shared module both commands call                                                                                                                                                              |

## Deviations

| What                                    | Why                                                                                                                                                   |
| --------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------- |
| SHA-256 before `timingSafeEqual`        | evidence's length short-circuit leaks the credential's length by timing                                                                               |
| `charset="UTF-8"` on the challenge      | RFC 7617 §2.1 allows it and it fixes non-ASCII credentials; evidence omits it                                                                         |
| Warn on a half-set credential pair      | evidence silently ignores `EVIDENCE_BASIC_USER` without `EVIDENCE_BASIC_PASSWORD`; a half-set pair is a mistake worth naming                          |
| No HSTS, no COOP, no CORP               | HSTS is the TLS terminator's header and inert over HTTP; `CORP: same-site` would break the shipped `/data/` + `/widgets/` embeds (ADR-0025, ADR-0027) |
| `serve` is `mpa`, `preview` stays `spa` | preview is the authoring parity check (misses answer the shell); serve is the production contract (misses answer real status codes)                   |
