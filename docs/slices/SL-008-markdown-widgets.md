# SL-008 — `<Callout>`/`<Note>`/`<LineBreak>`/`<Details>`/`<Tabs>`/`<Accordion>`/`<Row>`/`<Stack>`: markdown layout and disclosure widgets

Milestone: Phase 1 — A usable BI-as-code product · State: open · Depends on: SL-001 · Closes: —

## Outcome

A page author composes prose and data widgets inside eight new tags — `<Callout type="warning" title="…">`, `<Note>`, `<LineBreak lines={2} />`, `<Details title="…" open>`, `<Tabs><Tab title="…">`, `<Accordion><AccordionItem title="…">`, `<Row>`, `<Stack>` — resolving through `mdxComponents`, nesting each other and any data widget, keyboard-accessible (tablist arrow nav, disclosure triggers), and repainting under the light/dark toggle. Misuse (`<Tab>` outside `<Tabs>`, missing `title`) renders an inline `role=alert` instead of taking the page down.

## Demo

1. Cold start: `pnpm install && pnpm build:cli`, then `bin/biac dev` from the repo root, open `http://localhost:5175/weekly-review`.
2. Under "Overview", three `<BigValue>`s sit in a `<Row>` — equal thirds side by side; a `<Note>` under them reads as muted small text.
3. A `<Callout type="info" title="…">` near the top renders a blue-tinted bordered panel; a `<Callout type="warning" title="Concentration risk">` beside the regional-split prose renders amber.
4. "Metric definitions" sits inside `<Details title="Metric definitions">` — collapsed with a right-pointing chevron; click opens it and rotates the chevron; a second `<Details open>` starts open. `<Details openMobile>` resolves against the viewport only at mount.
5. "Order mix" gains `<Tabs>` — "Chart" keeps the scatter chart, "Table" shows a `<Table>` of the same fence: click switches panels; ArrowLeft/ArrowRight move tab focus (base-ui roving tabindex); switching back preserves the table's sort and scroll (panels stay mounted).
6. A closing `<Accordion single>` holds "Methodology" and "Data quality" `<AccordionItem>`s — opening one closes the other; a second `multiple` accordion on the page allows both open; closed panels are findable via browser Ctrl+F (`hiddenUntilFound`).
7. One `<Row>` cell carries a `<Stack>` of a `<Value>` line over a `<Note>`; a `<LineBreak lines={2} />` visibly widens one section gap.
8. Click the theme toggle — callouts, tablist, accordion and details repaint in the dark palette without a reload; click back.
9. Resize to ~500px: `<Row>` children wrap to full-width lines; the tablist scrolls horizontally instead of overflowing the page.
10. Temporarily add a bare `<Tab title="x">` at top level → inline `role=alert` says it must be a direct child of `<Tabs>`; a paragraph inside `<Tabs>` gets the same treatment. Revert.
11. `console` stays clean throughout (the `/favicon.ico` 404 is the tracked known-debt exception).

**Named disagreements the slice must resolve:**

- **Child collection:** evidence mounts children hidden + context-store registration (Svelte can't introspect child props); streamlit composes real containers; React reads props off child elements — the registration machinery is unneeded.
- **Disclosure element:** framework demos native `<details>`; evidence rolls button+slide; streamlit ships a controlled expander. Controlled is required for `openMobile`.
- **Row semantics:** evidence = flex-wrap + per-child `width` + grow fix-up; framework = fixed `grid-cols-N` classes; streamlit = ratio `spec` + fixed 640px wrap. We have no per-widget `width` system, so equal-share flex-wrap is our model.
- **Multi-open default:** evidence `accordion` defaults to many-open (`single=false` opt-in); base-ui `Accordion.Root` defaults single-open (`multiple` opt-in) — the prop inverts.

## Deviations

- **No `icon` prop anywhere** — evidence's dynamic lucide-by-name (`common/dynamic-icon.ts` + `icon-names.ts` registry) is unported; `components/icons.tsx` is static. Additive later if a slice demands it.
- **No `width` attribute / per-child sizing** — no width system exists on our widgets, so evidence's `row-grouping.ts` ResizeObserver grow-fix, flush-density pilling and `componentWrapper` flex config are unported; streamlit's ratio `spec` likewise. `<Row>` children share equally.
- **No `print_break` / print unfurl** — no print mode exists (evidence unfurls tabs into headings under `getPrintModeContext`).
- **No `color`/`align` props on `<Tabs>`** — polish props; additive when demanded.
- **No `card` prop on `<Row>`/`<Stack>`** — it gates on evidence's `pageSettings.cards`/card chrome, which we don't have. Accordion's `variant="card"` stays — it's a visual style, not the card-mode system.
- **No `accordion_title`/`accordion_body_slot` slots** — `title` is a required string on `<AccordionItem>` (evidence's inline `validate` semantic, at runtime).
- **`<Note>` drops the `class` escape prop** — no `className` convention exists on our widgets.
- **Misuse is a runtime inline `role=alert`**, not a compile error — our pipeline has no schema validation layer (the `TableError` pattern); covers `<Tab>`/`<AccordionItem>` outside their parent, non-child elements inside `<Tabs>`/`<Accordion>`, missing `title`, and multiple `default` tabs.
- **`<Details>` is base-ui `Collapsible`, not native `<details>`** — controlled `defaultOpen` keeps `open`/`openMobile` parity with evidence and animates.
- **Prop names are camelCase** — `fullWidth`, `openMobile` (SL-006/007 precedent: evidence `bin_count` → `binCount`).

## Open decisions

- **Row wrap basis** — `basis-72` (288px, ≈ evidence's ~300px per-component `minWidth`) is the default; T5 measures wrap behavior at 1280px and ~500px on the demo page and adjusts if it reads wrong.
- **`keepMounted` chart repaint** — T3 verifies a mounted-but-hidden chart repaints at real size on tab reveal (the `echart.tsx` ResizeObserver should fire); if it doesn't, panels flip to lazy mount.
- **`<LineBreak>` markup** — evidence renders `lines` × `<br/>` inline; adopt verbatim unless the demo shows block-level spacing reads better.
- **`fullWidth`/`variant` keep-set** — both are cheap class maps adopted for evidence fidelity; review at T3/T4 can drop them before the slice ships (post-ship removal is a break).
