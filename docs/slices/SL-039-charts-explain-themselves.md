# SL-039 — Charts explain themselves

Milestone: Phase 2 — A polished UI · State: open · Depends on: SL-036 · Closes: GAP-023, GAP-024, GAP-025

## Outcome

A reader can tell what a chart plots, in what unit, and read each value once, without the surrounding prose: every chart widget takes a `title` and `subtitle` shown as text above the plot, a scatter's axes carry titles, a labelled bar chart drops the value axis its labels repeat, and an axis over whole numbers ticks on whole numbers.

## Demo

1. Cold start: `pnpm build:cli && bin/biac dev`, open `http://localhost:<port>/weekly-review` at 1280 px.
2. Regional split, Order mix and Order size each show a title line and a muted subtitle (unit included) above the plot. They are real DOM text: `playwright-cli eval` finds each string outside the canvas, and selecting it with the mouse works.
3. Regional split (`labels`) shows its 3 bar labels and no value-axis tick labels or horizontal gridlines. Each label keeps its own precision (`3.7k`, not `4k`).
4. Order mix: the x axis is titled (orders) and reads `0 5 10 15 20 25`. The y axis is titled (revenue).
5. Trend lines: the LineChart and AreaChart x axis (week) and the LineChart y axis (orders) read whole numbers with no `.0`.
6. Open `/crossfilter-scale`. The 3 histograms each show a title and a subtitle naming the unit, above the plot.
7. Repeat steps 2–5 at 375 px and in dark mode: the title wraps inside the chart's width, and the subtitle stays muted with readable contrast.
8. Brush a histogram on `/crossfilter-scale` and click a Regional split bar. Cross-filter behaves as before, and the title does not dim or move while the re-query is in flight.

**Where the references disagree:**

- **Title placement.** evidence and Plot put it in HTML above the chart; mosaic and streamlit don't have one. Nobody paints it inside the canvas, which is what we do today.
- **Default axis titles.** evidence defaults the y title to the series alias and hides the auto x title. streamlit shows the x column name only when `x` was explicit. Plot labels axes from the channel name by default.
- **Integer detection.** evidence reads the domain kind (grain or year-like), streamlit reads the column dtype. Our models carry plain values with no column types, so we can only read the values.
- **Gridlines.** On by default in evidence and streamlit (y), off by default in Plot and mosaic. None of them couple gridlines to data labels.

## Deviations

- Auto-hiding the value axis under `labels` has no reference implementation. It ports NN/g's rule, and the justification goes in a code comment citing the NN/g URL. If open decision 5 settles it, it becomes an ADR, because it changes what `labels` means for every bar chart.
- The canvas `title` is removed rather than kept as an option. Two renderings of one prop would drift.

## Open decisions

1. **HTML title in `BoundChart` vs the canvas title.** Settled in T1: HTML. `ChartFigure` (`src/web/src/features/widgets/charts/chart-heading.tsx`) renders title and subtitle above every face, outside the `aria-busy` region; `chartChromeOption` paints no echarts `title` and `gridOption` reserves room for the legend only.
2. **Heading semantics.** Settled in T1: `<figure aria-labelledby>` with non-heading `div` text. `src/web/src/features/chrome/toc-headings.ts` collects `h2, h3`, so a heading title would add TOC entries; `/weekly-review` TOC measured 7 entries before and after, `/crossfilter-scale` 3. `describeChart` keeps the generated canvas description.
3. **Default axis titles.** evidence/streamlit derive them; ours is author-set. Recommend author-set, so the demo pages set them. Settle in T2.
4. **Integer detection scope.** Value-based on every `value` axis (series x/y, scatter x/y). Confirm `bigint` cells (DuckDB `count(*)` is `BIGINT`) reach the models as `bigint` or `number`: `to-series.ts` accepts both. Settle in T3 with a unit test per kind.
5. **Labels drop the value axis.** Auto-hide on a non-stacked bar with `labels` (recommended, NN/g), or an evidence-style `gridlines` prop. Stacked bars keep the axis: their inside labels give segments, not totals. Line/area with `labels`: decide alongside (NN/g's example is a bar chart). Settle in T4, with an ADR.
