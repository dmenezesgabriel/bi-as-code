# SL-045 — A typo in `biac.config.ts` is a located error naming the key, the accepted ones and the closest match

Milestone: Phase 4 — Project and page settings, themes, layouts · State: open · Depends on: — · Closes: GAP-045

## Outcome

An author who mistypes a key in `biac.config.ts` (`pagewidth`, `nav: { sidebr: false }`) sees, in the `biac dev` browser overlay and terminal and as a failed `biac build`, an error at `biac.config.ts:<line>:<column>` naming the unknown key path, every accepted key and the closest one — instead of the key being ignored silently.

## Demo

1. Cold start: `pnpm build:cli && bin/biac dev`, open `http://localhost:5173/`; the page renders.
2. Add `pagewidth: "full",` as a top-level key in `biac.config.ts` and save — the browser shows vite's error overlay reading `Invalid biac.config.ts:<line>:<column> — pagewidth: unknown key, expected one of title, theme, nav, sql, interpreters`, the overlay's file link points at that line and column, and the terminal prints the same message with `File: …/biac.config.ts:<line>:<column>`.
3. Rename it `titel: "ACME"` — the message ends `(did you mean title?)`.
4. Delete the key, save, and reload the tab — the page renders again with no server restart (O3 decides whether the reload becomes automatic).
5. Set `nav: { sidebr: false }` — the error names `nav.sidebr`, expects `sidebar`, suggests `sidebar`.
6. With the typo in place, `bin/biac build` exits non-zero with the same message and writes no `build/`.
7. `sql: { anything: "data/channels.csv" }` and `interpreters: { ".pl": ["perl"] }` still load — their keys are user names, never checked.

**Count:** 2 of 4 reject or flag unknown keys (streamlit for app config, mosaic for specs); evidence and framework, the two BI-as-code products with a project config file, ignore them. None of the 4 gives a line and column or suggests the closest key — both are owner requests (2026-10-17): the line/column follows our own page compile errors (`src/engine/page-compile-error.ts` carries `line`/`column`), and the suggestion is an invention justified by the owner's request alone.
