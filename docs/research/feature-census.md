# Feature census — 4 reference repositories

**Ephemeral.** This is construction scaffolding: a map of which reference implementations have which capability, and the files to open. It is phase-scoped and deleted when Phase 1 closes. Nothing here belongs in a durable document — see [ADR-0001](../adr/0001-record-architecture-decisions.md).

## What this is for

A slice PRD must answer "who else built this, and how?" before proposing an approach. This file is the starting point so each PRD does not re-crawl 4 repositories. **It is a map, not a substitute for reading the code.** The PRD still opens the cited files and verifies them.

## How it was built, and what it cannot tell you

One pass over `research_repos/`, 2026-10-03: directory listings, package manifests, and targeted file reads (not symbol greps alone). Paths verified with `test -e` equivalents in-session.

Limits: counts are qualitative (FULL/PARTIAL/ABSENT) not measured tallies; paths rot slower than line ranges, so only paths are recorded; `streamlit` is a Python server+websocket product — its rows describe **widget UX/behavior** parity (its execution model does not apply to us).
