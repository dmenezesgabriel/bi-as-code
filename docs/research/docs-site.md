## Standards and platform facts

| Fact                                                                                                                                                                                    | Source                                                                                                                   |
| --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------ |
| A custom Pages workflow needs "`pages: write` and `id-token: write` permissions", `configure-pages`, `upload-pages-artifact`, `deploy-pages`; the default environment is `github-pages` | https://docs.github.com/en/pages/getting-started-with-github-pages/using-custom-workflows-with-github-pages              |
| "Published GitHub Pages sites may be no larger than 1 GB"; deployments time out after 10 minutes; soft bandwidth limit 100 GB per month                                                 | https://docs.github.com/en/pages/getting-started-with-github-pages/github-pages-limits                                   |
| A custom 404 page is a `404.html` (or `404.md` with `permalink: /404.html`) in the publishing source; the page does not state the status it is served with                              | https://docs.github.com/en/pages/getting-started-with-github-pages/creating-a-custom-404-page-for-your-github-pages-site |
| "Diátaxis identifies four distinct needs, and four corresponding forms of documentation - tutorials, how-to guides, technical reference and explanation"                                | https://diataxis.fr/                                                                                                     |

## Decisions the slices must make

| Id  | Decision                         | Options seen                                                                                                                                                                                                                                               |
| --- | -------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| D1  | Where the docs project lives     | `docs/` (framework) is taken by engineering docs; a separate project directory built with `biac build <dir>`                                                                                                                                               |
| D2  | Showing a snippet and its result | Write the markup twice (a fence and the live widget — they drift) vs one source that is both shown and rendered (framework `echo`). Our `echo` exists for SQL fences only ([ADR-0011](../adr/0011-a-named-sql-block-renders-nothing-unless-it-opts-in.md)) |
| D3  | Structure                        | Diátaxis's four kinds vs framework's feature-ordered tree; they combine (Getting started = tutorial, one reference page per widget)                                                                                                                        |
| D4  | Example data                     | Data files committed under the docs project (framework `docs/data/`) vs generated by loaders at build (framework `quakes.csv.js`, cached in CI); file size counts toward the 1 GB limit                                                                    |
| D5  | Publication trigger and cache    | On push to the default branch + manual (framework adds a daily cron for fresh loader data); cache `.biac/cache` as framework caches `.observablehq/cache`                                                                                                  |
| D6  | Broken links                     | Warn with a count (framework) vs fail the build; a docs site that ships broken internal links fails its readers                                                                                                                                            |
| D7  | Versioned docs                   | Neither framework nor mosaic versions its docs (one latest site); not proposed                                                                                                                                                                             |
