# Usability audit — a polished UI (Phase 2)

**Ephemeral.** Sibling of [`feature-census.md`](feature-census.md). It lists every place the shipped UI falls below a professional BI product, measured against evidence (the polish bar), Observable Framework, streamlit and published standards. Each shortfall is a `GAP-NNN` (numbering continues from the Phase 1 audit, whose GAP-001…016 all closed), and each gap names the backlog slice that closes it. The file is deleted when every gap is closed; anything durable becomes an ADR first. It records measurements and names decisions; it makes none.

## How this was built

- One `playwright-cli` pass (headless, session `r5`) over `bin/biac dev` at HEAD `5881527`, 2026-10-15. Routes: `/`, `/weekly-review`, `/nested/allocation`, `/nested/allocation?edit=true`, `/crossfilter-scale`, `/nope`, at 1280×800, 1920×1080 and 375×812, light and dark.
- Host at the start of the pass: `nproc` 8, 1 min load 8.74 (falling from 19.2 under another workload; `scripts/wait-for-host.sh` then exited 0), `MemAvailable` 5.6 GB, memory `some avg60` 0.11, 0 `veth` events in 10 min. Console: 0 errors, 0 warnings.
- The same probe ran on the live references: the evidence demo report <https://evidence-demo.netlify.app/> (and `/business-performance`), the evidence docs <https://docs.evidence.dev/components/data/data-table/> (current evidence UI; its table there is an image, so table rules come from source), and the Framework docs <https://observablehq.com/framework/sql> (built with Framework). `https://ecommerce.evidence.app/` no longer resolves (`DNS_PROBE_FINISHED_NXDOMAIN`).
- The probe is a `playwright-cli eval` over the live DOM. It reads `getComputedStyle` (font size/line height/weight, colour, padding, radius, `font-variant-numeric`) and `getBoundingClientRect` (positions, gaps between consecutive blocks of the page column). It computes WCAG relative-luminance contrast from colours resolved through a 1×1 canvas (the app's colours are `oklch`), characters per line as paragraph width over the width of a `0` glyph, and `document.documentElement.scrollWidth - innerWidth` for horizontal overflow. Focus was audited by pressing `Tab` 40 times from the top of `/weekly-review` and reading `document.activeElement`'s outline each time.
- Code-level counts come from `grep -rhoE "\b(text|bg|border)-(neutral|gray|slate|zinc)-[0-9]+\b" src/web/src --include='*.tsx' | grep -c .` (and the same over `research_repos/evidence/core/src --include='*.svelte'`). Radii come from `grep -rhoE "rounded(-[a-z0-9]+)?" src/web/src --include='*.tsx' | sort | uniq -c`.
- Palette separability is the minimum pairwise CIE76 ΔE in CIELAB over the first _n_ series colours, after simulating protan/deutan/tritan vision with the severity-1.0 matrices of Machado, Oliveira & Fernandes 2009 (<https://www.inf.ufrgs.br/~oliveira/pubs_files/CVD_Simulation/CVD_Simulation.html>, IEEE TVCG 15(6)), applied in linear sRGB.
- A **gap** is a measured shortfall where at least one reference does better (path cited, `test -e` verified in-session) or a published bar fails.
