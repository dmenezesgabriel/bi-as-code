# Usability audit — shipped Phase 1 rows

**Ephemeral.** Sibling of [`feature-census.md`](feature-census.md): every place a shipped Phase 1 row (SL-001…SL-017) works by its gates but falls short in the running app, measured. Each shortfall is a `GAP-NNN`; each gap names the backlog slice that closes it. Deleted when every gap is closed; anything durable becomes an ADR first. This file records measurements and names decisions — it makes none.

## How this was built

- One `playwright-cli` pass (headless, session `r3`) over `bin/biac dev` at HEAD `5ba4506`, 2026-10-10, then the same routes over `bin/biac build` + `bin/biac preview`.
- Host at the start of the pass: `nproc` 8, 1 min load 2.42, `MemAvailable` 18.9 GB, memory `some avg60` 0.00; the pass waited until three readings a minute apart were below `nproc`.
- Routes: `/`, `/weekly-review`, `/weekly-review?region=…`, `/nested/allocation`, `/nested/page`, `/crossfilter-scale`, `/nope`, `/weekly-review?edit`; at 1280×800 and 375×812, light and dark.
- Measurements are `playwright-cli eval` over the live DOM: `getComputedStyle` for type, spacing and color; `document.documentElement.scrollWidth - innerWidth` for horizontal overflow; WCAG relative-luminance contrast with colors resolved through a 1×1 canvas (the app's colors are `oklch`); `getBoundingClientRect` plus a 24 px-circle spacing test for target size; canvas `toDataURL` change detection for repaint latency; screenshots for what the DOM cannot say (canvas text).
- A **gap** is a measured shortfall where at least one reference does better (path cited, `test -e` verified in-session) or a universal bar fails. Universal bars, fetched in-session: [WCAG 2.2](https://www.w3.org/TR/WCAG22/) 1.3.1, 1.4.1, 1.4.3 (4.5:1 text), 1.4.10 (no horizontal scroll at 320 CSS px), [2.5.8 Target Size (Minimum)](https://www.w3.org/WAI/WCAG22/Understanding/target-size-minimum.html) (24×24 CSS px, or a 24 px circle spacing exception); no silent loss of unsaved work ([MDN `beforeunload`](https://developer.mozilla.org/en-US/docs/Web/API/Window/beforeunload_event): "intended to help prevent loss of unsaved data").
- The static build reproduces every page-level gap below (`/weekly-review` h1 16px/400, `p` margin 0px, 375 px overflow 504; `/crossfilter-scale` result tables of 2,901 and 3 × 200,000 rows); its console is empty and it has no `Edit` link.
