# Phase 1 exit demo

**Ephemeral.** The script a human runs to close Phase 1 — "`biac dev` serves markdown pages with live SQL widgets; filters and chart selections cross-filter them; `biac build` emits a static site" (`docs/backlog.md`, Phase 1). When a human has run every step and it passes, R4 becomes `shipped`, this file is deleted, and the later phases open.

## How to run it

- `pnpm build:cli` if `dist/cli/main.js` is older than `src/cli/`, then `bin/biac dev` (prints its URL, `http://localhost:5175/` in the rehearsal).
- Run part A at 1280×720 in a fresh browser profile, then part B after `bin/biac build` + `bin/biac preview` (`http://localhost:4173/`).
- Each step names what to do, what must be true, and how the rehearsal measured it. A step passes when its expected column holds; the human run fills the last column.
- If you save a page in step A11, undo the edit and save again — `git status --short` must be empty when you finish.

## Rehearsal conditions

- 2026-10-12, `playwright-cli -s=exit-demo` headless, 1280×720 unless stated, Chromium from `playwright-cli`.
- Host: 8 logical cores, 1 min load 7.90–9.27 during the run (`cut -d' ' -f1 /proc/loadavg`), memory `some avg60=0.00`. Latencies below are on that loaded host.
- `bin/biac build`: 7.86 s wall, 913,948 KB peak RSS (`/usr/bin/time -f "%e s, %M KB" bin/biac build`).
