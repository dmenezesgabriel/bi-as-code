# Settings and themes — 4 reference repositories and our gaps

**Ephemeral.** Construction scaffolding for Phase 4: which reference repos let a project and a page configure layout and appearance, the files to open, and what `biac.config.ts` and front-matter lack. Deleted when Phase 4 closes. Nothing here belongs in a durable document — see [ADR-0001](../adr/0001-record-architecture-decisions.md).

## How it was built

One pass over `research_repos/` on 2026-10-17: targeted reads of the files listed below, every path checked with `test -e`. Our side read in `src/` the same day (symbols cited, line numbers omitted because `src/web/src/features/pages/` had uncommitted work from a parallel session). External claims cite the URL fetched that day; https://docs.evidence.dev/features/project-settings, `/page-settings` and `/themes` were fetched and match `evidence/docs/features/*.mdx` in the clone (the live page-settings table also lists `down_is_good` and `downloads`, which the clone's copy does not).

## Decisions the slices must make

| Id  | Decision                                        | Options seen                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                 |
| --- | ----------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| D1  | Where settings live                             | Two YAML files (evidence) vs one TS config (framework, and ours since SL-002: `biac.config.ts`). Keeping one typed TS file is the lower-cost path; a separate theme file is only worth it if non-developers edit it                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                          |
| D2  | The `theme` key is taken                        | Ours: `theme` is the colour mode (`"light"`\|`"dark"`\|`"system"`, `src/engine/types.ts` `BiacTheme`). evidence's `theme` is colours, framework's is a list of theme names. The slice picks a non-breaking shape (e.g. a new key for brand colours) and records it in an ADR                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                 |
| D3  | Invalid values                                  | Drop silently (evidence `.catch(undefined)`, framework coercion) vs a located error naming the field, expected shape and value (ours: `src/engine/biac-config.ts` `invalid()`, the SL-020/SL-026 precedent). Ours is stricter and stays so                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                   |
| D4  | Theme model                                     | Named preset themes (framework) vs token overrides with light/dark pairs (evidence, streamlit). Our tokens are CSS custom properties in hex ([ADR-0014](../adr/0014-theme-tokens-are-css-custom-properties-in-hex.md)), so overrides map 1:1                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                 |
| D5  | Contrast of user colours                        | evidence derives text/borders from `base` "for good contrast"; streamlit takes colours as given. A user palette can break WCAG 2.2 1.4.3 (text 4.5:1) and 1.4.11 (non-text 3:1) (https://www.w3.org/TR/WCAG22/) and the CVD guarantee of [ADR-0016](../adr/0016-the-series-palette-is-chosen-for-colour-vision-deficiency.md): warn, fail, or derive                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                         |
| D6  | Partial palette override                        | Positional overlay — listed colours take the first slots, defaults fill the rest (evidence) vs replace the whole list                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                        |
| D7  | Which of evidence's remaining settings to build | Decided 2026-10-17 by reference count, fit with a static client-side build, and whether it overrides something that already exists. **Built**: theme style tokens that map 1:1 onto existing CSS custom properties — font families (evidence `fonts`, streamlit `font`/`headingFont`/`codeFont`, framework theme fonts: 3 of 4), base font size, `--radius`, `--positive`/`--negative`, `--field`, `--sidebar` (GAP-068, SL-063) — and a page icon in the sidebar (evidence `icon`, streamlit `st.Page(icon=…)`: 2 of 4; drawn from the already-wrapped icon set, GAP-069, SL-064). Fonts are chosen from system stacks (`sans-serif`\|`serif`\|`mono`, as evidence offers); loading remote font files is not offered — it adds a third-party request to every page. **Not built**: `auto_refresh` (evidence only; a static build's data changes only on redeploy, and dev refresh is SL-043); `date.first_day_of_week` and `date.default_date_range_end` (evidence only; `DATE_RANGE_PRESETS` in `src/web/src/features/widgets/inputs/resolve-date-range.ts` has no week preset for them to act on — revisit with one); `workflow.period` (evidence only; `<DateRange>` plus URL-persisted filters already select a period); a page-level `down_is_good` (the widget-level `downIsGood` on `<BigValue>` exists, and streamlit is per widget too, `delta_color`); `density`, `depth`, `chart.*`/`table.*` behaviour toggles (evidence only; chart ink is decided by ADR-0015). `downloads` belongs to the later **Table extras** phase and `type: partial` to **Templating** |
