# Self-hosting and authentication — 4 reference repositories and our gaps

**Ephemeral.** Construction scaffolding for Phase 7: deploying a biac project on infrastructure the owner runs — AWS or any other cloud, a container or a bucket — with no auth, HTTP basic auth, or SSO. biac offers no hosted service. Deleted when Phase 7 closes. Nothing here belongs in a durable document — see [ADR-0001](../adr/0001-record-architecture-decisions.md).

## Owner decisions (2026-10-17)

| Decision                                                                                                                                            | Consequence for the slices                                                                                                                                                                                            |
| --------------------------------------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Self-hosting only — no hosted service                                                                                                               | Every deploy target is the owner's: a container, a bucket, a static host                                                                                                                                              |
| SSO is an authenticating reverse proxy in front of biac; biac ships no OIDC code (evidence's model, not streamlit's in-app OIDC)                    | biac never handles tokens, cookies or IdP secrets; the example ships the proxy configuration                                                                                                                          |
| `biac serve` (production server) plus the static `build/` folder, with basic auth or an explicit no-auth opt-out in `biac serve` (evidence's model) | `biac preview` stays a local preview; `biac serve` is the hardened server                                                                                                                                             |
| The worked example's bucket is moto server (owner decision 2026-10-17, D11): the most S3-API-compatible stand-in available locally                  | The example is a local demonstration of the T3 shape, never a production store; the same nginx/proxy and upload steps target AWS S3 or any S3-compatible store in production                                          |
| Caddy stands in for the ALB in the worked example (owner decision 2026-10-17, D12)                                                                  | Caddy `forward_auth` to oauth2-proxy (Keycloak OIDC) gates every request; Caddy terminates TLS and redirects HTTP to HTTPS                                                                                            |
| Keycloak stands in for Microsoft Entra ID in the worked example (owner decision 2026-10-17, D13)                                                    | One realm per tenant, one client per app registration, client roles emitted as `roles`, mappers for `oid`/`tid`/`groups`/`preferred_username`; oauth2-proxy uses `keycloak-oidc` locally and `entra-id` in production |

## Decisions the slices must make

| Id  | Decision                                   | Options seen                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                               |
| --- | ------------------------------------------ | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| D1  | What `biac serve` is built on              | vite `preview()` (today's `biac preview`, bound to vite's defaults — [ADR-0008](../adr/0008-static-build-is-a-spa-folder.md)) vs a small Node `http` server over `build/` owned by biac. Must keep byte ranges (DuckDB reads parquet by range — measured `206` today), SPA fallback, correct media types, and put auth before every response including static files (evidence's lesson: its static branch "returns before SvelteKit hooks run")                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                            |
| D2  | Auth configuration                         | Environment only (evidence, 12-factor): `BIAC_BASIC_USER`, `BIAC_BASIC_PASSWORD`, `BIAC_AUTH_DISABLED` honoured only for exact `1`/`true`. Boot refuses a non-loopback bind with neither, naming both variables                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                            |
| D3  | Credential comparison                      | evidence's length-short-circuit `timingSafeEqual` vs hash-then-compare (no length leak). Basic only behind TLS (RFC 7617 §4): `biac serve` speaks HTTP and expects a TLS terminator (ALB, nginx, ingress); HSTS is the terminator's header                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                 |
| D4  | Security headers                           | evidence's three vs the OWASP set. `X-Frame-Options`/`frame-ancestors` follows the Phase 6 embed allowlist (`docs/research/embeds.md` D1). Hashed `assets/` can be `immutable`; today `biac preview` sends `Cache-Control: no-cache` on them (measured)                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                    |
| D5  | Deep links on hosts with no rewrite        | (a) copy the SPA shell to `<route>/index.html` for every manifest route at build — works on S3 website endpoints (index document per folder), GitHub Pages and Garage with no host rule; this is not the "SSR or prerendering" row ADR-0008 rejected, because the shell is the same file and the client renders as today; (b) host fallback (nginx `try_files`/`error_page`, Pages `404.html`, Garage `--error-document`) — the fallback may carry a 404 status; (c) only `biac serve`. Choosing (a) supersedes ADR-0008's "needs a host-side fallback" consequence                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                        |
| D6  | Base path                                  | Absolute base set at build (`vite --base`, router `basepath`, data URLs from `import.meta.env.BASE_URL`) vs relative `./`. Relative breaks under D5(a) copies one level down; absolute is configured once in `biac.config.ts`                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                              |
| D7  | Identity behind the proxy                  | biac reads no identity header (evidence: "Evidence does not read the authenticated user's identity from the proxy"). | D12 | Which proxy stands in for the ALB          | **Decided (owner, 2026-10-17): Caddy.** For the parts the example uses, Caddy behaves closer to an ALB: TLS on by default with HTTP→HTTPS redirect (ALB + ACM and its `redirect` action); `forward_auth` is a standard directive that passes the auth gateway's response straight to the client and copies identity headers (ALB `authenticate-oidc` redirect + `X-AMZN-OIDC-*` headers), where nginx needs `auth_request` (not built by default in source builds), `auth_request_set` and an `error_page 401` redirect. | D13 | Which IdP stands in for Microsoft Entra ID | **Decided (owner, 2026-10-17): Keycloak, shaped like Entra.** No self-hosted IdP reproduces Entra's URLs or the `login.microsoftonline.com` issuer that oauth2-proxy's `entra-id` provider enforces; the dedicated Entra emulators are months old with 0–61 stars and fail the maintenance bar, and `mock-oauth2-server` is test-only. Of the maintained IdPs, Keycloak maps closest to Entra's model: realm ≈ tenant, client ≈ app registration, client roles ≈ app roles emitted as `roles`, groups, per-client claim mappers that can emit `oid`/`tid`/`preferred_username`, brokering and AD/LDAP federation; it is the widest-adopted (37,414 stars) and a CNCF Incubating project. authentik can shape the same claims with Python property mappings; Authelia is a certified OIDC provider but a sign-in portal over file/LDAP users, the furthest from a directory like Entra. MSAL clients reach any of them with `protocolMode: "OIDC"` (MSAL.js) or `oidc_authority` (MSAL Python). biac itself uses no MSAL: the example's oauth2-proxy uses `keycloak-oidc` locally and `entra-id` in production, a one-provider swap documented side by side |
