## Standards that bind the design

| Fact                                                                                                                                                                                          | Source                                                                                                      |
| --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------- |
| CSP `frame-ancestors` takes `'none'`, `'self'`, host and scheme sources; "This directive is not supported in the `<meta>` element" — it must be an HTTP response header                       | https://developer.mozilla.org/en-US/docs/Web/HTTP/Reference/Headers/Content-Security-Policy/frame-ancestors |
| "Content Security Policy (CSP) frame-ancestors directive obsoletes X-Frame-Options for supporting browsers"; OWASP's default is `X-Frame-Options: DENY`                                       | https://cheatsheetseries.owasp.org/cheatsheets/HTTP_Headers_Cheat_Sheet.html                                |
| "Always specify an exact target origin, not `*`, when you use `postMessage`" and "always verify the sender's identity using the `origin`" — the framework example's `"*"` is not to be copied | https://developer.mozilla.org/en-US/docs/Web/API/Window/postMessage                                         |

## Decisions the slices must make

| Id  | Decision                          | Options seen                                                                                                                                                                                                                                                                                                                                                     |
| --- | --------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| D1  | Who may frame a page              | Nobody (evidence `DENY`, OWASP default) vs a configured allowlist sent as `Content-Security-Policy: frame-ancestors 'self' <origins>`. Default stays deny; embedding is an explicit allowlist. `biac serve` sends it; a bucket or CDN host needs the same header from its proxy (Phase 7)                                                                        |
| D2  | Chrome-less pages                 | Per-page front-matter switches (framework `sidebar`/`header`/`footer`/`pager`) vs one embed query parameter. Ours has only the project-wide `nav.sidebar` in `biac.config.ts`                                                                                                                                                                                    |
| D3  | Frame height                      | Fixed height vs a resize message to the parent — with an exact `targetOrigin` taken from the allowlist, never `"*"`                                                                                                                                                                                                                                              |
| D4  | Which files are exported          | Explicit list (framework `dynamicPaths`) vs everything under `build/data/` (ours already copies `data/` unhashed). Cross-origin fetches also need `Access-Control-Allow-Origin` from whoever serves them                                                                                                                                                         |
| D5  | Exported modules — unit and shape | framework exports any module returning a DOM node. Ours renders React widgets fed by DuckDB-WASM in a worker: an export must carry React, the widget CSS without leaking into the host page (Shadow DOM or a scoped root), and resolve the wasm/worker/data URLs against the publishing origin. The largest and riskiest item in this phase; it is proposed last |

## Gap analysis — ours against `framework`

| Gap     | Concern                        | framework                                        | Ours                                                                                                                                                                                                                                                                                                                                       | State   |
| ------- | ------------------------------ | ------------------------------------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | ------- |
| GAP-052 | Chrome-less page for an iframe | front-matter `sidebar`/`header`/`footer`/`pager` | `biac.config.ts` `nav.sidebar` is project-wide (`src/engine/biac-config.ts` `readSidebar`); no page can drop the sidebar, header or ToC rail alone                                                                                                                                                                                         | partial |
| GAP-053 | Framing policy                 | host's concern                                   | Measured: `curl -s -D - http://localhost:8933/weekly-review` on `bin/biac preview` returns no `X-Frame-Options` and no `Content-Security-Policy`, so any origin can frame any page; nothing lets a project allow some origins and deny the rest                                                                                            | absent  |
| GAP-054 | Responsive frame height        | example `ResizeObserver` + `postMessage`         | none                                                                                                                                                                                                                                                                                                                                       | absent  |
| GAP-055 | Exported files at stable URLs  | `dynamicPaths`, static or loader-generated       | `build/data/` is copied unhashed, so `/data/orders.parquet` is stable — measured `200` on `biac preview`, and `Range: bytes=0-3` → `206`, `Content-Range: bytes 0-3/3440`. With `-H 'Origin: https://other.example'` the response has no `Access-Control-Allow-Origin` and an empty `Content-Type:`, so a cross-origin page cannot read it | partial |
| GAP-056 | Exported modules               | `dynamicPaths` JS modules                        | none — `biac build` emits one SPA entry (`build/index.html` + `build/assets/`)                                                                                                                                                                                                                                                             | absent  |
