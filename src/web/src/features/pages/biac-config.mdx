# biac.config.ts

`biac.config.ts` holds the settings that belong to the whole project: its name, theme, sidebar, layout, data tables, loader languages, brand and deploy path. Every key is optional.

The reader-facing reference is `docs/pages/pages/biac-config.md` (`/pages/biac-config` in `bin/biac dev docs`). It lists every key with its values, its default and the error a wrong value raises; the keys that change what a reader sees have a story here. `base`, `sql`, `interpreters` and the `embed.dataOrigins` grant change no pixel, so they have no canvas.

## `title`

`title` is the site's name, shown at the top of the sidebar.

```ts
export default { title: "Sales" };
```

## `theme`

`theme: "dark"` opens the site in dark mode for a reader who has not picked a mode of their own.

```ts

```

## `nav`

`nav.sidebar: false` removes the sidebar and its toggle, and the content fills the window.

```ts
export default { nav: { sidebar: false } };
```

## `directories`

A `directories` entry replaces a folder's name in the sidebar and the breadcrumb; the URL keeps the folder name.

```ts
export default {
  directories: { "pages/q3-reports": { title: "Quarter 3" } },
};
```

## `embed`

`embed.origins` lists the sites allowed to show the pages in an iframe. A framed page posts its height to a listed parent, so the parent can size the frame.

```ts
export default {
  embed: { origins: ["https://intranet.example.com"] },
};
```
