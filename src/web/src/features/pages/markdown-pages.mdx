# Markdown pages and front-matter

A biac page is a Markdown file under `pages/`: its path is its URL, and an optional YAML block at the top sets how the page is named, ordered, laid out and searched.

The reader-facing reference is `docs/pages/pages/markdown-pages.md` (`/pages/markdown-pages` in `bin/biac dev docs`). It lists the route rules, every front-matter key and the icon catalog; the keys that change what a page looks like have a story here.

## Sidebar

### Icons

`icon` names one glyph from a fixed catalog; the sidebar draws it before the page's label.

```yaml
icon: calendar
```

## Layout

### Page width

`page_width: full` lifts the reading column's width limits so the content fills the space beside the sidebar.

```yaml
page_width: full
```

### Cards

`cards: true` puts each chart, table and big value on its own card over a tinted background.

```yaml
cards: true
```

### Without the table of contents

`table_of_contents: false` hides the rail that lists the page's headings.

```yaml
table_of_contents: false
```
