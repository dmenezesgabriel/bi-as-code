# Row

`<Row>` places its children side by side and shares the width equally between them: a line of headline numbers, two charts to compare. When the page is too narrow for every child to keep about 192 px, the row wraps onto more lines; on a phone-width window (narrower than 768 px) each child takes the full width, one under the other.

The reader-facing reference is `docs/pages/layout/row.md` (`/layout/row` in `bin/biac dev docs`); each example there has a story here.

### Vertical alignment

`align` sets where children shorter than the row sit: `top`, `center`, `bottom`, or `stretch` (the default) to the height of the tallest. On a phone-width window the children are stacked, so `align` has nothing to align.

<Canvas of={RowStories.AlignCenter} />

## Props

| Prop    | Type                                           | Default     | What it does                            |
| ------- | ---------------------------------------------- | ----------- | --------------------------------------- |
| `align` | `"top"`, `"center"`, `"bottom"` or `"stretch"` | `"stretch"` | Where children shorter than the row sit |

## Errors

An `align` outside the four names shows a message where the row would be, naming the value and the four it accepts; the rest of the page still renders.
