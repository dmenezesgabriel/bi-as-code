# Tabs

`<Tabs>` shows one of several panels at a time, under a row of tabs that switch between them: a chart and the table behind it, or the same chart for each species. Each panel is a `<Tab>` whose children are Markdown and widgets. With the keyboard, the arrow keys move between tabs and select the one they land on. A panel that is not showing stays loaded, so a widget inside keeps its sort order, scroll position or selection when the reader switches away and back.

The reader-facing reference is `docs/pages/layout/tabs.md` (`/layout/tabs` in `bin/biac dev docs`); each example there has a story here.

## Props

### Tabs

| Prop        | Type                    | Default     | What it does                                      |
| ----------- | ----------------------- | ----------- | ------------------------------------------------- |
| `variant`   | `"default"` or `"well"` | `"default"` | An underlined row, or buttons in a shaded tray    |
| `fullWidth` | boolean                 | `false`     | Stretch the row and share it equally between tabs |

### Tab

| Prop      | Type    | Default  | What it does                        |
| --------- | ------- | -------- | ----------------------------------- |
| `title`   | string  | required | The tab's label                     |
| `default` | boolean | `false`  | Select this tab when the page loads |

## Errors

A mistake in the markup shows as a message where the tabs would be, and the rest of the page still renders: a `variant` outside the two names, a child of `<Tabs>` that is not a `<Tab>`, a `<Tab>` without a `title`, more than one `default` tab, or a `<Tab>` outside `<Tabs>`.
