# Histogram

`<Histogram>` shows how the values of one numeric column spread out: it cuts the range of the `value` column into bins of equal width and draws one bar per bin, as tall as the number of rows that fall in it. To compare amounts across categories, use a Bar chart.

The query returns the rows themselves, one per observation, and the histogram counts them. Unlike the other charts, the query does not group: a `group by` would leave one row per group to count.

The reader-facing reference is `docs/pages/components/histogram.md` (`/components/histogram` in `bin/biac dev docs`); each example there has a story here.

## Examples

### Bins from a query

`data` and `value` are all a histogram needs. With no bin props, the number of bins follows the number of rows: twice the cube root of the row count, rounded up. Hover a bar to read its bin's range and count.

<Canvas of={HistogramStories.RiceRuleDefault} />

### Split by a column

`series` names a column whose values split each bar, one colour per value. The series always stack, so the bar's height is still the bin's total.

<Canvas of={HistogramStories.StackedByRegion} />

### Bin count

`binCount` sets how many bins the range is cut into.

<Canvas of={HistogramStories.ExplicitBinCount} />

### Bin width

`binWidth` sets each bin's width in the column's units, and the number of bins follows from it. It wins when both `binWidth` and `binCount` are set.

### Value labels

`labels` prints each bar's count on it.

### Label format

`labelsFmt` formats the labels with a format code from the Value page. Without it, labels follow `yFmt`, which defaults to whole numbers.

### Colour

`color` paints every bar one CSS colour.

<Canvas of={HistogramStories.Color} />

### Series colours

`seriesColors` maps a series name to a CSS colour. Series it does not name keep the theme's colours.

<Canvas of={HistogramStories.SeriesColors} />

### Value format

`valueFmt` formats the values on the axis and the bin range in the tooltip. With no `valueFmt`, the axis shortens large values (`6k`) while the tooltip gives the bin's edges in full (`6,043 – 6,300`). The axis marks round values, not the bin edges, so its labels stay apart whatever the bin width.

<Canvas of={HistogramStories.ValueFormat} />

### Y format

`yFmt` formats the count axis and the counts in the tooltip. Counts are whole, so with no `yFmt` they show as whole numbers.

<Canvas of={HistogramStories.YFormat} />

### Title and subtitle

`title` heads the chart and `subtitle` sits under it, both above the plot.

<Canvas of={HistogramStories.TitleAndSubtitle} />

### Axis titles

`xTitle` names the bin axis and `yTitle` the count axis, which is titled Frequency until you name it.

<Canvas of={HistogramStories.AxisTitles} />

### Without the legend

A histogram with more than one series shows a legend. `legend={false}` hides it; the tooltip still names each series.

<Canvas of={HistogramStories.NoLegend} />

### Height

`height` sets the chart's height in pixels. The width always fills the column.

<Canvas of={HistogramStories.Height} />

### SVG renderer

`renderer="svg"` draws the chart as SVG instead of on a canvas, which keeps it sharp when zoomed or printed.

<Canvas of={HistogramStories.SvgRenderer} />

### Narrow with a filter

`filters` names the page filters whose selections narrow the chart's query. A filter narrows on its `valueColumn`, so the query must return a column of that name. The bins stay where they were, so the narrowed shape compares with the whole. `filters` also takes a list, `filters={["island", "species"]}`, and every listed filter narrows the query.

<Canvas of={HistogramStories.Filtered} />

### Select to cross-filter

`select="crossfilter"` lets a reader select on the histogram: drag across bars to select a range of the `value` column, or click a legend entry to select a series. The selection is a filter named after the selected column, so it narrows every widget whose `filters` name that column. Click the plot to clear it. Give each chart both `select` and `filters` and the selections run both ways; a chart is never narrowed by its own selection.

<Canvas of={HistogramStories.SelectCrossfilterBrush} />

## Errors

A mistake in a histogram's markup shows as a message where the chart would be, and the rest of the page still renders. The message names the query and what is wrong: a `data` that names no fence on the page, a `value` or `series` the query does not return (with the columns it does return), or a format code the column cannot take. A query that returns no rows, or none with a number in `value`, shows "0 rows" in the chart's place, at the chart's height. Rows whose `value` is empty are not counted.
