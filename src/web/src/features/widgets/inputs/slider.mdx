# Slider

`<Slider>` is a track a reader drags to pick a number, or a range of two, and hands the pick to the page's queries and to the widgets that list its `id` in `filters`. The pick is written to the page URL, so a reload or a shared link opens the page with it as it was left.

The reader-facing reference is `docs/pages/filters/slider.md` (`/filters/slider` in `bin/biac dev docs`); each example there has a story here.

## Examples

### Narrow a widget

`data` names the query the slider's ends come from, and `valueColumn` the column whose smallest and largest values they are. A widget that lists the `id` in `filters` keeps the rows at least the pick.

### Set the ends and the step

`min`, `max` and `step` set the slider's ends and how far one move goes. They work without `data`. Page Up and Shift+Arrow move a tenth of the range in whole steps.

### Start on a value

`initialValue` is the pick the page opens with when the URL holds none. A range slider takes a pair. A pick outside the slider's ends moves to the nearest end.

## Props

| Prop           | Type                      | Default          | What it does                                                          |
| -------------- | ------------------------- | ---------------- | --------------------------------------------------------------------- |
| `id`           | string                    | required         | The filter's name: in widgets' `filters`, the URL and `{{params.id}}` |
| `data`         | string                    | —                | The query the slider's ends come from                                 |
| `valueColumn`  | string                    | —                | The column the ends come from and widgets are narrowed on             |
| `min`          | number                    | the query's, 0   | The lower end                                                         |
| `max`          | number                    | the query's, 100 | The upper end                                                         |
| `step`         | number                    | `1`              | How far one move goes                                                 |
| `range`        | boolean                   | `false`          | Draw two thumbs and keep the rows between them                        |
| `title`        | string                    | `id`             | The label above the slider                                            |
| `initialValue` | number, or a pair         | —                | The pick the page opens with when the URL holds none                  |
| `filters`      | string or list of strings | —                | Other filters that narrow the query the ends come from                |

## Errors

A `<Slider>` with `data` but no `valueColumn`, or whose `data` names no query on the page, or whose query fails, shows a message in place of the slider; so does one whose `min` is larger than its `max`. The rest of the page still renders. A value in the URL outside the slider's ends moves to the nearest end.
